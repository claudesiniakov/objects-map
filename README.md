# Карта объектов

Веб-сервис: интерактивная карта объектов разных типов с зонами-радиусами в метрах и кластеризацией. Объекты загружаются из Excel через панель управления.

- **Карта** (`/`) — маркеры по типам, зоны в реальных метрах, кластеры с числом объектов, составом по типам и суммарной стоимостью (тыс. руб. → «12,4 млн ₽»), «веер» для объектов в одной точке, легенда с фильтрами по типам, фильтры по источнику и по дополнительным полям, поиск, карточка объекта. Состояние карты, включая фильтры, хранится в URL.
- **Полигоны** — объекты могут иметь контур (GeoJSON Polygon/MultiPolygon, WGS-84). Загружаются импортом файла `.geojson` (свойства объектов — колонки, сопоставляются как в Excel) или колонкой «Геометрия (GeoJSON)» в Excel/CSV. Маркер ставится посередине контура (гарантированно внутри, даже у вогнутых полигонов), поэтому кластеры, суммы, поиск и карточки работают как у точек; в карточке — площадь. На карте: слой «Полигоны» (показать/скрыть) и фильтр «Геометрия» (все / полигоны / точки). Экспорт в GeoJSON — в «Объектах»; его можно загрузить обратно. Радиус типа по умолчанию к полигонам не применяется. Контур редактируется в форме объекта (Mapbox GL Draw): нарисовать, тянуть вершины, добавить вершину на стороне, удалить выделенное, несколько контуров — мультиполигон; маркер вне нового контура сервер переносит внутрь, новый объект можно создать только контуром.
- **Поиск адресов** — в строке поиска: объекты ищутся по мере ввода, адрес — по Enter или пункту «Найти адрес». Геокодер — OpenStreetMap Nominatim (на сайте через `/api/geocode`: не чаще 1 запроса в секунду, с кэшем; в скачанной карте — напрямую). Карта центрируется на адресе и ставит метку; по щелчку на метке задаются радиус зоны и цвет. Метку можно сохранить — она личная (видна только своему пользователю), появляется в панели «Фильтры» → «Мои метки» (показать/скрыть на карте, перейти, удалить); название, радиус и цвет сохранённой метки меняются в её окне и сохраняются автоматически. В скачанной HTML-карте личных меток нет.
- **Комментарии** — сворачиваемый блок в карточке объекта: текст, автор и время. Добавлять может любой вошедший пользователь, удалять — автор или администратор; всё пишется в журнал. При импорте в режиме «Заменить» комментарии переносятся на пересозданный объект с тем же ID (и обратно при откате). В скачанной HTML-карте комментарии только для чтения.
- **Панель управления** (`/admin`) — импорт Excel (проверка → предпросмотр → запись одной транзакцией → откат), объекты (таблица, ручное редактирование с картой, массовые действия, экспорт), справочник типов, пользователи и роли, настройки карты, журнал изменений.
- **API** — REST, документация OpenAPI: `/api/docs`.

## Стек

| Слой | Технология |
| --- | --- |
| Фронтенд | HTML + JavaScript-модули без сборки, MapLibre GL JS 4 (CDN) |
| Кластеризация | Supercluster, встроенный в MapLibre |
| Бэкенд | Python 3.12, FastAPI, Uvicorn |
| Excel | openpyxl (`.xlsx`), xlrd (`.xls`), csv |
| База | SQLite (WAL), индексы по координатам |
| Подложка | OpenStreetMap |

Вариант «SQLite вместо PostgreSQL/PostGIS» и фронтенд без сборки выбраны под ресурсы сервера (ТЗ допускает упрощённую базу для пилота). Переход на PostgreSQL затрагивает только `backend/app/db.py` и SQL-запросы.

## Формат Excel

Шаблон скачивается в панели управления («Импорт» → «Скачать шаблон»). Колонки: `ID`, `Номер договора`, `Кадастровый номер`, `Тип`*, `Название`*, `Широта`*, `Долгота`*, `Адрес`, `Радиус, м`, `Стоимость, тыс. руб.`, `Описание`; остальные колонки сохраняются как дополнительные поля. Тип указывается кодом или названием из справочника. Кадастровый номер проверяется на формат `77:01:0001001:1234` — при несовпадении строка загружается с предупреждением. Поиск ищет и по номеру договора, и по кадастровому номеру.

**Скачать HTML** (кнопка на карте) — сохраняет одну HTML-страницу с объектами, которые сейчас на экране с учётом фильтров. Страница открывается без сервера и входа: кластеры, зоны, карточки, поиск и фильтры работают по встроенным объектам; библиотека MapLibre встроена в файл, из интернета грузятся только тайлы OpenStreetMap (без них объекты видны на пустом фоне). Если JavaScript в просмотрщике выключен, показывается таблица объектов. Скачать можно и без объектов на экране — получится пустая карта со справочником типов. В скачанной странице есть **«Импорт CSV»** (или перетащить файл в окно): колонки как в шаблоне импорта (ID, Номер договора, Кадастровый номер, Тип, Название, Широта, Долгота, Адрес, Радиус, Описание, Источник), остальные колонки — дополнительные поля. Кодировка UTF-8 или Windows-1251 и разделитель «;», «,» или табуляция определяются сами. Если на карте уже есть объекты, можно заменить их или добавить новые (объекты с тем же ID обновляются). Типы, которых нет в справочнике, показываются серым; строки без названия или координат пропускаются с отчётом по номерам строк.

Код карты общий для обоих режимов: `static/js/data.js` отдаёт данные из API или из встроенного снимка, `static/js/download.js` собирает страницу, `static/js/csv.js` разбирает CSV.

Поля для фильтров задаются в «Настройках» (по умолчанию «Ответственный»): это названия колонок Excel, до 5 штук. По каждому появляется выпадающий список на карте и в разделе «Объекты», экспорт учитывает выбранные значения.

Режимы импорта: **Добавить**; **Обновить / добавить** (по ID); **Заменить** (объекты того же источника удаляются и загружаются заново). Откатывать импорты можно по порядку, начиная с последнего.

## Локальный запуск

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
cd backend && OBJMAP_DATA_DIR=../data ../.venv/bin/uvicorn app.main:app --port 8092
```

Статику (`static/`) нужно отдавать вместе с проксированием `/api/` на порт 8092 — см. `deploy/nginx.conf`.

Тестовые данные: `.venv/bin/python tools/make_test_xlsx.py 10000 test.xlsx --errors`.

## Развёртывание на сервере

| Что | Где |
| --- | --- |
| Код | `/var/www/objects-map` (автодеплой из bare-репозитория `/root/objects-map-bare.git`, ветка `main`) |
| Данные: база, загруженные файлы, иконки, бэкапы | `/var/lib/objects-map` |
| API | systemd `objects-map.service`, `127.0.0.1:8092`, пользователь `objmap` |
| Веб | nginx, порт `8088` (`deploy/nginx.conf`) |
| Бэкап | `objects-map-backup.timer`, ежедневно в 03:30, хранение 14 дней |

Выкладка новой версии: `git push deploy main`. Хук `deploy/post-receive` обновляет код, при изменении `requirements.txt` ставит зависимости, перезапускает сервис и обновляет конфиг nginx.
